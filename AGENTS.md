# Agent Instructions

Este repositorio armazena skills pessoais. Mantenha as mudancas pequenas e
organizadas por responsabilidade.

## Convencoes

- Use o formato `Categoria/nome-da-skill/SKILL.md`.
- Nao misture arquivos de skills diferentes no mesmo commit quando as mudancas
  forem independentes.
- Preserve arquivos auxiliares dentro da pasta da skill que os usa.
- Atualize `README.md` quando criar, remover ou mover uma skill.
- Nao faca push sem pedido explicito do usuario.

## Git

- Antes de commitar, rode `git status --porcelain`.
- Use `git add` com caminhos explicitos.
- Prefira commits focados e mensagens em portugues.
- Depois de commitar, confirme `git status --short --branch`.
